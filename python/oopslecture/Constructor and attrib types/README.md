# Constructor

it's a built-in python method used to make class's method provide functionality to give arguments like simple method/functions
and these methods are also known as: **dunder magic method** </br>
**method name:** `__init__`  these method start with double under score.

## Syntax

**code example ⤵**

```python
class Human:
    def __init__(self,name,gender): # Constructor now class also can take arguments and parameter like other methods
        self.name=name # instance attributes
         self.gender=gender 
```
